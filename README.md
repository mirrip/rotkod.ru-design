# rotkod.ru-design

Отдельная адаптивная страница, точно воспроизводящая утверждённый дизайн РодКод.

## Реализация

- на ширине более 820 px показывается самостоятельная ПК-версия;
- на ширине 820 px и меньше показывается самостоятельная мобильная версия;
- оригинальный макет используется как точный визуальный слой без перерисовки и расхождений;
- поверх макета размещены реальные кликабельные зоны меню, кнопок, карточек и ссылок;
- скрытая семантическая структура сохраняет заголовки и смысловые разделы для доступности.

Файл `assets/design-reference.png` — утверждённый пользователем визуальный референс.
