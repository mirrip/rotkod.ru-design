# rotkod.ru-design

Отдельная адаптивная демонстрационная страница «РодКод», собранная по утверждённому визуальному макету.

## Реализация

- главный экран полностью собран из живых HTML-элементов, а не из зафиксированного снимка;
- заголовки, описания, кнопки, карточки, этапы и навигация остаются настоящими текстовыми и интерактивными элементами;
- тёмная поверхность под текстом и светлая зона под будущую фотографию разделены самостоятельными слоями;
- форма перехода создана CSS-кривой с полупрозрачной размытой кромкой и тонким золотым контуром;
- карточки проекта содержат отдельные изображения, подписи, номера и ссылки;
- интерфейс получает деликатное движение, подсветку, реакцию на указатель и плавное появление блоков;
- компьютерная и мобильная композиции адаптируются без горизонтальной прокрутки;
- мобильная версия использует крупную горизонтальную витрину и закреплённую панель быстрых действий;
- изображения карточек загружаются отложенно, а интерфейс не зависит от внешнего сервера шрифтов;
- тяжёлые эффекты указателя и анимации появления отключены на сенсорных устройствах;
- при включённом системном ограничении анимации движение автоматически отключается;
- каждая кликабельная область открывает простую страницу соответствующего раздела;
- семантическая разметка, заголовки и читаемый текст доступны браузерам и поисковым системам.

Основная мобильная точка перестроения — `760px`.
