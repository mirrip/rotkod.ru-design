# rotkod.ru-design

Отдельная адаптивная демонстрационная страница РодКод, точно повторяющая
утверждённый визуальный макет.

## Реализация

- для компьютерной и мобильной версий используются отдельные точные области
  изображения `assets/design-reference.png`;
- композиция пропорционально масштабируется по ширине экрана без искажений и
  горизонтальной прокрутки;
- поверх изображения размещены настоящие прозрачные ссылки для меню, кнопок,
  карточек, этапов и нижней навигации;
- каждая кликабельная область открывает простую страницу соответствующего
  раздела;
- в документе сохранены заголовок, описание и семантический текст для базовой
  доступности и индексации.

Переключение между компьютерным и мобильным кадром происходит на ширине
`760px`.
