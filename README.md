# rotkod.ru-design

Отдельный адаптивный сайт РодКод, собранный по утверждённому визуальному
референсу.

## Реализация

- интерфейс состоит из настоящих HTML-объектов, текста, кнопок и карточек;
- композиция плавно масштабируется для компьютеров, планшетов и телефонов;
- белая область в первом экране зарезервирована под будущую фотографию;
- изображения карточек кадрируются отдельно и сохраняют пропорции;
- все кнопки и карточки кликабельны и открывают страницу выбранного раздела;
- предусмотрены семантическая разметка, метаданные и доступная навигация.

Файлы `assets/design-reference.png` и `assets/design-reference.webp` сохранены
только как исходные визуальные референсы и не используются как слой интерфейса.
